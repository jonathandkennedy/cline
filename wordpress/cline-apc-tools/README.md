# CLINE APC WordPress plugin

Zip **this folder** (`cline-apc-tools`) and upload it on lemonlawlawyerscalifornia.com:

**Plugins → Add New → Upload Plugin**.

Full rollout steps: [`docs/phase-1-embed.md`](../../docs/phase-1-embed.md).

Shortcodes:

```
[cline_form source="header-popup"]
[cline_eligibility]
[cline_buyback]
[cline_checklist]
```

Leads are emailed by the tools app (Resend), not by PHP.
